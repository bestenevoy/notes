# 算法

刷题中积累的惯用法与证明，重点放在能迁移回工程的部分：复杂度直觉、位运算惯用法、边界条件的处理。

- [位运算与状态压缩](位运算与状态压缩.md) — 整数即集合的约定、`bit_count` / `bit_length` / lowbit 三件套、枚举元素与枚举子集的三种循环，附两个用位性质秒杀的例题。
- [堆与二分查找](堆与二分查找.md) — 三部分：`heapq`（只保证 `h[0]`）、`bisect`（返回分界索引）、标准库工具箱（`collections` / `itertools` / `functools` / `math` / `graphlib` / 内置），第三部分每个工具配可运行程序 + 逐行拆解 + 与暴力实现的对拍；含 Top-K 的 `k` 盈亏平衡实测、976 的斐波那契截断证明、3.14 最大堆 API、`@cache` 深链上限卡在 1095 且提不动、`isqrt` 与 `int(sqrt)` 的出错量级、`graphlib` 波次循环、陷阱清单与移植对照表。
